# FORGE ITALY

Immersive Italian café website and reservation platform.

## Stack
Next.js 16 · React 19 · Three.js / React Three Fiber · GSAP · Framer Motion · Supabase

## Supabase setup
1. Create a Supabase project.
2. Run `supabase/schema.sql` in the SQL editor.
3. Add these Vercel environment variables:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_DASHBOARD_KEY`
4. Redeploy.

## Routes
- `/` cinematic homepage
- `/menu` menu
- `/reservations` real reservation form
- `/admin` protected operations dashboard
- `/experience`, `/story`, `/gallery`, `/events`, `/contact`
